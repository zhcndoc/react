<Intro>

React 的开发工作由来自世界各地公司和社区的贡献者共同推动。

</Intro>

React 的工作由多个工作组负责，每个工作组负责项目的一个领域，例如服务器、DOM、Fiber、文档与社区、编译器、开发者体验（DevX）和 React Native。每个工作组都由 React 领导委员会中的代表参与，该委员会负责协调整个项目的发展方向。
